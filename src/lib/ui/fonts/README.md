# Study typography

These fonts are bundled locally, without runtime font-service requests.

- Pixelify Sans: pixel headings and branding. [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/pixelifysans); license in `OFL-PixelifySans.txt`.
- VT323: narrower body text and native controls. [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/vt323); license in `OFL-VT323.txt`.

The generated study's lettering is a visual reference, not an available font file.
Both fonts retain their original names and files.
