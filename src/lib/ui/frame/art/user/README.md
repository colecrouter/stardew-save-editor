# Wood frame

These user-authored PNGs are directly editable production assets. Keep transparent
corners/caps intact and render at integer 3x scale; no crop/export command is needed.

- `frame.png`: 55×45, source slices 10 on each edge, rendered at 30px.
- `post.png`: 7×50, seven-pixel top/bottom caps with a repeated middle.
- `post-horizontal.png`: 43×7, seven-pixel left/right caps with a repeated middle.

Border-image owns tile placement; do not position separate corners/middle pieces.
