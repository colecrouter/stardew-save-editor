# Application mark

The barn, save journal and pencil connect farming with editing. Match the page
sprites' warm palette and upper-left lighting, with more room for roof, wood and
paper detail. Keep the combined silhouette readable at header size.

`app-mark.png` is a **128×128 transparent PNG**. `AppMark.svelte` displays
it at 144px on the upload page and 48px in the editor header, reserving a square
before loading. Pixelated sampling preserves the finished artwork's hard edges.

The adjacent app name supplies the accessible label; the image is decorative.
Replace the PNG directly to update both placements. The favicon is separate.
